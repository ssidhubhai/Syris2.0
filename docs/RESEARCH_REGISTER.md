# RESEARCH_REGISTER.md — Things To Verify Before/While Coding

## Provider/API research

- Current Gemini model IDs and lifecycle.
- Current Gemini API version and recommended API surface.
- Current Gemini free-tier and rate-limit behavior.
- Current Mistral Free mode and exact eligible models.
- Current NVIDIA free endpoint availability.
- Current alternate provider free/development limits.
- Structured-output and tool-calling differences across providers.
- Vision/audio capabilities per approved model.

## Rendering research

- Best SVG/Canvas approach for educational diagrams.
- MathLive/KaTeX trade-offs.
- Graph layout libraries for explanation relationships.
- Browser performance of large SVG/Canvas documents.
- Responsive digital-paper layout.
- Accessibility of math and diagrams.

## Pedagogical research

- Visual density vs cognitive load.
- Good handwritten JEE solution patterns.
- Effective annotation/arrow usage.
- When diagrams improve vs distract.
- Student preference for Hinglish/technical terminology.
- Reference/navigation patterns that reduce backtracking.

## Content/retrieval research

- JEE content sources and rights/licensing.
- Reliable metadata for questions.
- Concept dependency representation.

## Security/operations

- upload limits;
- secret management;
- logging/retention;
- provider terms for student content;
- rate limiting.

Do not turn a research placeholder into an implementation assumption without recording the source/decision.
